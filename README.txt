================================================================================
软件名称：键客 KeySentry
版本: v3.1.0.1126
支持系统: Windows 7 / Windows 10 / Windows 11 (32位 & 64位)
开发语言: C++17 / Win32 API
编译工具: CMake + Visual Studio
软件作者：Marvin
软件简介：一款掌控你的键盘和窗口的轻量工具，提供按键禁用、按键映射、热键管理、窗口隐藏（老板键）、窗口置顶、启动时设置等实用功能，帮助用户自定义键盘行为和系统设置。

功能介绍
================================================================================
一、锁定键状态提示
功能说明：按下 Caps Lock / Num Lock / Scroll Lock 或静音键时，在屏幕上显示当前状态浮层，默认 1 秒后自动消失。
浮层外观可自定义：
- 颜色：深色（默认）、浅色。
- 位置：底部（默认）、顶部、居中、左侧、右侧。
- 边框：直角、圆角（默认）。
- 透明度：高透明、适中、低透明（默认）、不透明。
- 延时：快速（0.5 秒）、适中（1 秒，默认）、缓慢（2 秒）、保持显示（浮层常驻置顶，不自动隐藏）。
- 仅在主屏显示提示：勾选后只在主显示器的浮层显示。

二、按键屏蔽
功能说明：允许用户阻止特定按键的输入，避免误操作。

三、按键映射
功能说明：将某个按键重新定义为另一个按键或组合键（如 C → Ctrl+C），目标按键通过虚拟键盘选择，支持 Ctrl/Shift/Alt/Win 修饰键，实现键盘布局的自定义调整。
- 按键互换：支持两个按键双向互换（如 CapsLock ⇄ Ctrl、Ctrl ⇄ Alt），列表中合并显示为一行，删除该行会同时移除两个方向。
- 方向列：列表按"原始按键 | 方向 | 映射目标"展示，"映射 →"表示单向映射，"互换 ⇄"表示双向互换。

四、热键管理
- 自定义热键：可自行添加热键，设置执行的命令/程序路径、运行参数、工作目录、描述信息；也可选择"打开文件/目录"模式快速打开常用文件或文件夹，或选择"模拟按键"模式，通过热键模拟任意按键输入。
- 启用/停用：可一键启用或停用自定义热键功能。

五、窗口隐藏（老板键）
- 启用窗口隐藏：通过快捷键一键隐藏/恢复指定窗口，保护隐私。
- 鼠标触发：支持鼠标中键、侧键1、侧键2触发隐藏。鼠标移至屏幕四角（左上/右上/左下/右下）触发隐藏，带1秒防抖。
- 闲置自动隐藏：检测到用户闲置指定时间（1-120分钟可调）后自动隐藏窗口。
- 隐藏时静音：隐藏窗口的同时自动静音系统，恢复时还原。
- 隐藏当前窗口：除绑定列表外，额外隐藏当前前台窗口。
- 暂停媒体播放：隐藏前自动暂停媒体播放。
- 退出时关闭已隐藏程序：退出键客时关闭（而非恢复）已隐藏的进程。
- 异常自愈：隐藏窗口信息实时写入恢复文件，键客异常退出后重新启动会自动恢复之前隐藏的窗口，避免窗口"失踪"。
- 窗口/进程绑定：
  - 按窗口标题匹配：仅匹配包含指定标题的窗口。
  - 按进程名匹配：匹配该进程的全部窗口，包括后续新建的窗口。
  - 支持从当前运行窗口列表中选择绑定，也支持手动输入窗口标题。
- 托盘菜单操作：窗口隐藏时可通过托盘菜单"恢复隐藏窗口"恢复；窗口未隐藏时可通过"隐藏窗口"菜单触发隐藏。

六、窗口置顶
- 启用窗口置顶：对指定窗口或进程保持置顶激活状态，并禁止被最小化，实现对返回桌面等操作快捷键（如 Win+D）的免疫。
- 修复窗口堆叠：若出现窗口异常置顶的情况，可点击"修复窗口堆叠"按钮，强制取消所有窗口的置顶状态，恢复正常窗口层级。
- 窗口/进程绑定：与窗口隐藏功能共享绑定机制，支持窗口标题匹配和进程名匹配。
- 持续监控：每3秒复核已锁定窗口，约每9秒全量扫描一次新出现的匹配窗口。

七、软件启动时设置
- 功能说明：在软件启动或者应用设置时，自动重置资源管理器的文件夹选项。
- 隐藏文件和文件夹：可设置为保持原状、隐藏、显示。
- 隐藏已知文件类型的扩展名：可设置为保持原状、隐藏、显示。
- 隐藏受保护的操作系统文件：可设置为保持原状、隐藏、显示。
- 生效时机：软件启动时自动应用，也可在设置对话框中点击确定或应用按钮即时生效。

八、外观主题
- 托盘菜单"外观"提供跟随系统 / 浅色 / 深色三种模式，切换后立即生效并保存。
- 深色模式覆盖标题栏、选项卡、表头、表格网格线与禁用态。
- 开启 Windows 高对比度时，设置界面自动回退为系统配色，保证文字可读。


使用注意事项
================================================================================
1. 管理员权限：键客本身不需要管理员权限，所有功能（热键注册、全局钩子、窗口置顶等）在普通用户权限下即可正常工作。仅在自定义热键中勾选"以管理员运行（UAC）"时，会触发 UAC 提权启动子进程。
2. 单实例运行：键客同一时间只允许运行一个实例。重复启动时会自动激活已运行实例的设置窗口。
3. 热键冲突：如果自定义的热键与其他软件冲突，键客会在应用设置时给出提示。建议避免使用系统保留热键（如 Ctrl+Alt+Del、Win+L 等）。
4. 窗口隐藏功能：
   - 若键客异常退出（如进程被杀），重新启动键客后会自动恢复之前隐藏的窗口，无需手动处理。
   - 开启"退出时关闭已隐藏程序"选项后，退出键客时会直接关闭而非恢复已隐藏的程序，请注意保存工作。
   - 系统关机/注销时，键客会以短超时快速收尾，不会拖慢关机速度。
5. 窗口置顶功能：
   - 启用窗口置顶后，被锁定的窗口将始终保持在最前方，可能影响其他窗口的操作。
   - 如果出现窗口异常置顶无法取消的情况，请使用"修复窗口堆叠"功能。
   - 窗口置顶会禁止被锁定窗口的最小化操作。
6. 按键屏蔽与映射：
   - 屏蔽按键后，该按键在所有程序中都不会响应，请谨慎配置。
   - 按键映射是通过拦截源按键并模拟目标按键实现的，个别程序可能无法正确接收模拟按键。
   - 不支持将一个按键映射为已被其他按键映射为源的按键（防止循环映射）。
7. 鼠标角落触发：角落触发的检测区域为屏幕四角 10×10 像素范围，并带有1秒防抖机制，避免误触发。
8. 闲置自动隐藏：闲置检测基于系统全局输入状态，不仅限于键客窗口的输入。
9. 配置文件：键客的配置文件为 KeySentry.ini，默认与程序同目录；若程序所在目录不可写（如安装在 Program Files），配置会自动保存到 %APPDATA%\KeySentry\KeySentry.ini。配置以 UTF-16（含 BOM）保存，可正常保存中文、emoji 等字符，也可用记事本直接编辑；如需备份设置，复制该文件即可。
10. 显示支持：本版本声明系统级高 DPI 感知，字体与控件随系统 DPI 同比放大，高分辨率/高缩放比例下不再模糊或偏小；仍兼容 Windows 7 SP1。若缩放后窗口超出可用桌面，程序会自动限制最大缩放倍数，保证窗口完整可见。
11. 安全软件：部分安全软件可能会拦截全局键盘钩子或热键注册，如遇功能异常，请将键客添加到安全软件的信任列表中。
12. 软件启动时设置：此功能会修改 Windows 资源管理器的全局设置，影响所有用户打开的文件资源管理器窗口。设置后如需恢复，可通过 Windows 设置或资源管理器菜单手动调整。

v1.21.0.1009
- 修复：按下 Scroll Lock（含用 Fn 组合键实现的键盘）时浮层疯狂闪烁、系统卡顿、任务栏卡死的问题。
- 原因：锁键被按住时系统会持续产生连发消息，旧版本对每次连发都发送浮层通知，且用状态取反推算新状态（连发时结果失真），同时每次通知都无条件重新置顶并整窗重绘，形成置顶重排与重绘风暴。
- 处理：仅在物理按下的第一次通知（NumLock 屏蔽分支同样只在首次注入按键），keyup 清除标志并带 3 秒超时兜底；浮层增加内容一致/80 毫秒去抖与按需置顶重绘。
