# 键客 KeySentry

一款掌控你的键盘和窗口的轻量 Windows 工具，纯 C++17 / Win32 API 实现，无任何第三方依赖。

## 功能特性

### 🔒 锁定键状态提示
- 按下 Caps Lock / Num Lock / Scroll Lock 或静音键时，在屏幕上显示当前状态浮层，浮层外观可自定义
- 「仅在主屏显示提示」：勾选后只在主显示器的浮层显示

### ⌨️ 按键屏蔽
- 阻止特定按键的输入，避免误操作

### 🔄 按键映射
- 将某个按键重新定义为另一个按键或组合键（如 `C → Ctrl+C`、`V → Ctrl+V`），目标按键通过虚拟键盘选择，自定义键盘布局。
- 支持两个按键双向互换（如 CapsLock ⇄ Ctrl、Ctrl ⇄ Alt），底层保存为两条反向映射，列表中合并显示为一行

### 🎨 外观主题
- 托盘菜单「外观」支持跟随系统 / 浅色 / 深色，切换后立即生效并保存
- 深色模式覆盖标题栏、选项卡、表头、表格网格线与禁用态
- 开启 Windows 高对比度时，设置界面自动回退为系统配色，保证可读性

### ⚡ 热键管理
- 添加热键执行命令/程序、打开文件或目录，或通过热键模拟任意按键与组合键

### 🕵️ 窗口隐藏（老板键）
- 快捷键一键隐藏/恢复指定窗口，保护隐私
- 鼠标中键、侧键、屏幕四角触发（带防抖）
- 闲置自动隐藏（1-120 分钟可调）
- 隐藏时自动静音、暂停媒体播放
- 支持窗口标题匹配 / 进程名匹配两种绑定方式
- **异常自愈**：程序崩溃后重启可自动恢复之前隐藏的窗口

### 📌 窗口置顶
- 对指定窗口/进程保持置顶，免疫 Win+D 等操作
- 持续监控：每 3 秒复核已锁定窗口，约每 9 秒全量扫描一次新出现的匹配窗口
- 一键修复窗口堆叠异常

### 🗂️ 启动时设置
- 启动时自动重置资源管理器文件夹选项（显示/隐藏文件、扩展名、系统文件）

## 下载使用

前往 [Releases](../../releases) 页面下载最新版本（当前 **v3.2.0.1128**），解压后直接运行：

| 文件 | 适用系统 |
|------|---------|
| `KeySentry-x86.exe`（32 位，675KB） | Windows 7 SP1 及更高（32/64 位通用） |
| `KeySentry-x64.exe`（64 位，820KB） | Windows 10/11（64 位） |

两个版本功能完全一致，均无需安装运行库，按系统位数选择即可。

## 验证下载文件与安全说明

本工具的 exe 若**尚未进行代码签名**，从浏览器下载后可能被 Microsoft SmartScreen 拦截，属正常现象：

- **浏览器下载提示"可能有害/不常见"**：文件来自网络且无下载信誉，SmartScreen 会对未签名文件一律拦截
- **首次运行出现"Windows 已保护你的电脑 / 未知发布者"**：点击「更多信息 → 仍要运行」即可

**校验下载完整性（SHA-256）**：Releases 页面为每个文件附有 SHA-256 值，下载后可比对：

```powershell
Get-FileHash .\KeySentry-x86.exe -Algorithm SHA256
```

## 从源码构建

```
要求：Visual Studio 2019+（含 C++ 桌面开发工作负载）、CMake 3.15+
```

```powershell
cmake -S . -B build -G "Visual Studio 17 2022"
cmake --build build --config Release
# 默认按主机架构构建，产物位于 release\KeySentry-x64.exe
# 32 位构建：cmake -S . -B build32 -G "Visual Studio 17 2022" -A Win32
# VS 2019 请将生成器改为 "Visual Studio 16 2019"
```

## 使用注意事项

- **管理员权限**：键客本身**不需要**管理员权限，所有功能（热键注册、全局钩子、窗口置顶等）在普通用户权限下即可正常工作。仅在自定义热键中勾选"以管理员运行（UAC）"时，会触发 UAC 提权启动子进程
- **单实例**：重复启动会自动激活已运行实例的设置窗口
- **配置文件**：默认为程序同目录的 `KeySentry.ini`；目录不可写时自动回退到 `%APPDATA%\KeySentry\`。配置以 UTF-16（含 BOM）保存，可正常保存中文、emoji 等字符，也可用记事本直接编辑
- **安全软件**：如遇弹窗拦截或功能异常，请将键客添加到安全软件信任列表；浏览器下载拦截与启动提示的说明见[验证下载文件与安全说明](#验证下载文件与安全说明)
