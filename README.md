# 键客 KeySentry

一款掌控你的键盘和窗口的轻量 Windows 工具，纯 C++17 / Win32 API 实现，无任何第三方依赖。

## 功能特性

### 🔒 锁定键状态提示
按下 Caps Lock / Num Lock / Scroll Lock 或静音键时，在屏幕上显示当前状态浮层，默认 1 秒后自动消失。

浮层外观可自定义（5 项，按 3 列排列）：

| 选项 | 可选值 |
|------|--------|
| 颜色 | 深色（默认） / 浅色 |
| 位置 | 底部（默认） / 顶部 / 居中 / 左侧 / 右侧 |
| 边框 | 直角 / 圆角（默认） |
| 透明度 | 高透明 / 适中 / 低透明（默认） / 不透明 |
| 延时 | 快速（0.5 秒） / 适中（1 秒，默认） / 缓慢（2 秒） / 保持显示 |

- 修改后点击「应用」立即生效，正在显示的浮层会同步换到新位置
- 「默认」按钮一键恢复：深色 / 底部 / 圆角 / 低透明 / 适中
- 「仅在主屏显示提示」：勾选后只在主显示器的浮层显示

以上 5 个外观选项与「仅在主屏显示提示」仅在「锁定键状态提示」或「静音状态提示」至少一项开启时可用，否则整体置灰。

### ⌨️ 按键禁用
阻止特定按键的输入，实现按键屏蔽，避免误操作。

### 🔄 按键映射
将某个按键重新定义为另一个按键或组合键（如 `C → Ctrl+C`、`V → Ctrl+V`），目标按键通过虚拟键盘选择，自定义键盘布局。

### ⚡ 热键管理
- **自定义热键**：添加热键执行命令/程序，或通过热键模拟任意按键与组合键（虚拟键盘选择，支持 Ctrl/Shift/Alt/Win 修饰键）
- **启用/停用**：一键启用或停用全部自定义热键

### 🕵️ 窗口隐藏（老板键）
- 快捷键一键隐藏/恢复指定窗口，保护隐私
- 鼠标中键、侧键、屏幕四角触发（带防抖）
- 闲置自动隐藏（1-120 分钟可调）
- 隐藏时自动静音、暂停媒体播放
- 支持窗口标题匹配 / 进程名匹配两种绑定方式
- **异常自愈**：程序崩溃后重启可自动恢复之前隐藏的窗口

### 📌 窗口置顶
- 对指定窗口/进程保持置顶，免疫 Win+D 等操作
- 持续监控：每 3 秒自动检测，锁定被意外取消置顶的窗口
- 一键修复窗口堆叠异常

### 🗂️ 启动时设置
启动时自动重置资源管理器文件夹选项（显示/隐藏文件、扩展名、系统文件）。

## 下载使用

前往 [Releases](../../releases) 页面下载最新版本（当前 **v2.0.0.1101**），解压后直接运行：

| 文件 | 适用系统 |
|------|---------|
| `KeySentry-x86.exe`（32 位，421KB） | Windows 7 SP1 及更高（32/64 位通用） |
| `KeySentry-x64.exe`（64 位，534KB） | Windows 10/11（64 位） |

两个版本功能完全一致，均无需安装运行库，按系统位数选择即可。

## 验证下载文件与安全说明

本工具的 exe 若**尚未进行代码签名**，从浏览器下载后可能被 Microsoft SmartScreen 拦截，属正常现象：

- **浏览器下载提示"可能有害/不常见"**：文件来自网络且无下载信誉，SmartScreen 会对未签名文件一律拦截
- **首次运行出现"Windows 已保护你的电脑 / 未知发布者"**：点击「更多信息 → 仍要运行」即可

**校验下载完整性（SHA-256）**：Releases 页面为每个文件附有 SHA-256 值，下载后可比对：

```powershell
Get-FileHash .\KeySentry-x86.exe -Algorithm SHA256
```


## 使用注意事项

- **管理员权限**：键客本身**不需要**管理员权限，所有功能（热键注册、全局钩子、窗口置顶等）在普通用户权限下即可正常工作。仅在自定义热键中勾选"以管理员运行"时，会触发 UAC 提权启动子进程
- **单实例**：重复启动会自动激活已运行实例的设置窗口
- **配置文件**：默认为程序同目录的 `KeySentry.ini`；目录不可写时自动回退到 `%APPDATA%\KeySentry\`
- **安全软件**：如遇弹窗拦截或功能异常，请将键客添加到安全软件信任列表；浏览器下载拦截与启动提示的说明见[验证下载文件与安全说明](#验证下载文件与安全说明)
